# Bulbasaur Python Runners

This folder contains three beginner-friendly Python runners themed around Bulbasaur.

Runners:

- `runner1_hello.py`: prints a simple greeting.
- `runner2_stats.py`: demonstrates variables, numbers, strings, and arithmetic.
- `runner3_growth.py`: EXP calculator using `argparse` and a small loop to simulate gaining EXP.

Examples:

Run the hello script:

```
python3 runners/bulbasaur_python/runner1_hello.py
```

Run the stats demo:

```
python3 runners/bulbasaur_python/runner2_stats.py
```

Run the growth/EXP calculator non-interactively:

```
python3 runners/bulbasaur_python/runner3_growth.py --level 5 --exp 120
```
